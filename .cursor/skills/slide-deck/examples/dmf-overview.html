DMF v0.1

02 · Level 2

Managed

Basic standards, inconsistent enforcement

Someone owns documentation and a few standards exist. The team still depends on heroics. Reviews, tooling, and intake are uneven across products.

  • A style guide exists but is not used in every review
  • Some products have coverage; others do not
  • Work is tracked, but intake is still informal

Next move Make the standard the default path: templates, a required review, and one source of truth. That is Structured.

Ryan Lake · DocFoundry · The Doc Guy
This is where most “we have a style guide” teams actually live. The artifact is there. The path is optional.
DocFoundry

DMF v0.1

03 · Level 3

Structured

Governance defined, workflows repeatable

Governance is written down. Writers follow the same intake, draft, review, and publish path. The operation is repeatable even when the calendar is not quiet.

  • Templates and a review workflow are in daily use
  • Tooling is chosen and shared across the team
  • New writers can be onboarded without shadowing one person

Next move Instrument the workflow. Measure cycle time, coverage, and review load, then automate the handoffs. That is Optimized.

Ryan Lake · DocFoundry · The Doc Guy
Structured is the default path, including the week the calendar is on fire. That is the distinction this talk is for.
