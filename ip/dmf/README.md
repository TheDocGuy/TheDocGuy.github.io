## What is the DMF?

The Documentation Maturity Framework is a 5-level model for evaluating, benchmarking, and systematically scaling documentation functions inside organizations. It gives documentation leaders and teams a shared language to assess where they are, identify gaps, and build a roadmap toward sustainable, high-velocity documentation operations.

---

## The 5 Levels

| Level | Name | Description |
|---|---|---|
| 1 | **Reactive** | Ad hoc documentation, no formal processes or ownership |
| 2 | **Managed** | Basic standards, inconsistent enforcement |
| 3 | **Structured** | Governance defined, workflows repeatable |
| 4 | **Optimized** | Automation, metrics, and continuous improvement are embedded |
| 5 | **Systemic** | Documentation as organizational infrastructure |
